# Skill icon sources

- [Skill Icons](https://github.com/tandpfun/skill-icons/tree/7f7e691e71aec64e8354bf697835e009d1ad80f8) provides the core icons, PostgreSQL, Redis, RabbitMQ, Kafka, Kubernetes, NGINX, and GitHub Actions. See [LICENSE](LICENSE).
- [Devicon](https://github.com/devicons/devicon/tree/32fe1d3b3f36ad11f90ab94f7db59738139c2bf6) provides Django REST Framework, SQLAlchemy, JSON Web Tokens, Helm, and pytest. See [LICENSE.devicon](LICENSE.devicon).
- [Simple Icons](https://github.com/simple-icons/simple-icons/tree/801eaab5b70f4933137069397ebbd2ce5f9ad56e) provides Pydantic, MinIO, Celery, and Ruff. See [LICENSE.simple-icons](LICENSE.simple-icons).
- [Docker Compose](https://github.com/docker/compose/blob/60046ef6022f64924562cb01806aaee0353ea5a1/logo.png) provides the Compose mascot. See [LICENSE.docker-compose](LICENSE.docker-compose).

The added tile backgrounds and sizes align the artwork with the existing Skill Icons. The logos identify their respective technologies.
